# Welcome to Docsy

Docsy is a **headless RAG component** designed for developers who want to add AI-powered documentation chat to their applications without fighting complex frameworks.

## The Problem

Building a documentation chatbot shouldn't require weeks of research, vendor comparisons, and infrastructure decisions. You just want users to ask questions and get accurate answers from your docs.

Yet every solution either:

- Forces you into a no-code dashboard (loses flexibility)
- Requires learning Python frameworks (you're a TypeScript dev)
- Locks you into their LLM/vector DB (vendor lock-in)
- Takes days to set up (just to try it out)

## Our Vision

**Docsy should feel like adding authentication with Clerk** - install, configure, done.

We're building the developer-first RAG layer that:

- Installs via npm in seconds
- Configures with TypeScript (type-safe, autocomplete)
- Integrates with tools you already use (Vercel AI SDK, Next.js)
- Lets you swap providers without rewriting code
- Stays out of your way

## What Docsy Is

A **modular RAG pipeline** you control completely:

- CLI for ingestion (`docsy ingest`)
- Core library for retrieval/generation
- TypeScript-first with full type safety
- Open source (MIT license)
- Built for the Next.js/Vercel ecosystem

## What Docsy Isn't

- Not a SaaS platform (you own your infrastructure)
- Not a UI library (bring your own components)
- Not a generic AI wrapper (opinionated for docs)
- Not enterprise software (built by developers, for developers)

## Current State

**Alpha** - The foundation works. Naive RAG is production-ready. Advanced patterns are in development.

We're building in public. Expect rough edges, but also expect rapid iteration based on real developer feedback.

## Who This Is For

You're a TypeScript/Next.js developer who:

- Has documentation that needs AI chat
- Wants control over your RAG pipeline
- Prefers code over dashboards
- Values simplicity over enterprise features

If that's you, welcome. Let's build something useful together.
